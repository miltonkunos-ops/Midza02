Live sync

Connect both phones to a free online database so sales and stock update on both phones automatically. It still works offline and catches up when you’re back online.
How to set up the database (once)
  1. Open console.firebase.google.com and sign in with a Google account.
  2. Add project. Name it, turn off Google Analytics, then create it.
  3. Build, then Firestore Database, then Create database. Pick the closest location and start in production mode.
  4. Open the Rules tab. Delete what’s there, paste the rules from the button above, and tap Publish.
  5. Project settings (gear icon), Your apps, web icon, register the app. Copy the firebaseConfig block.
  6. Paste it above and tap Connect. Then copy the setup code and send it to your co-owner. They paste it here and tap Connect.
Anyone who has the setup code can see and change your data, so send it only to your co-owner.

Receipt printing

For a Bluetooth receipt printer: install the free RawBT app from the Play Store, pair your printer in Android’s Bluetooth settings, then choose it inside RawBT. The free version of RawBT may print a short notice at the bottom of each receipt.
Do this at the end of every day, in both directions: you send, they import, they send, you import. Sending also works as a backup if your phone is lost.
